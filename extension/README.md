# Causality VS Code Extension

Scaffold only. Registers a single `Causality: Hello World` command to verify that the
extension compiles, packages and activates.

## Development

```bash
npm run build --workspace causality-vscode      # compile to out/
npm run package --workspace causality-vscode    # produce causality-vscode.vsix
```

Press `F5` in VS Code with this folder open to launch an Extension Development Host.
